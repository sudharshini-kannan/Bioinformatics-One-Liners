# 🧬 Bioinformatics One-Liners

A collection of useful command-line one-liners for common bioinformatics tasks.

This repository contains practical commands for working with biological data formats and performing common analyses using Linux and command-line tools.

## 📂 Topics

- 🐧 Linux Commands
- 🧬 FASTA One-Liners
- 📊 FASTQ One-Liners
- 🔬 BAM/SAM One-Liners
- 🧪 VCF One-Liners
- ⚡ AWK, SED and GREP

## 🎯 Goal

The goal of this project is to build a practical reference for commonly used bioinformatics command-line operations.

Each section includes:

- Command
- Description
- Example
- Bioinformatics use case

## 🛠️ Tools

- Linux/Bash
- AWK
- SED
- GREP
- SAMtools
- BCFtools
